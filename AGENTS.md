# Japanese notes repository

- Lesson sources are LuaLaTeX files under `lv*/`; compile changed lesson files with
  `latexmk -lualatex` from their level directory when available.
- Reuse the shared files in `templates/`; do not duplicate their definitions.
- Preserve the existing SPDX/copyright header in new `.tex` files.
- Do not invent Japanese readings, translations, grammar explanations, or exercise
  answers from incomplete source material.
- For work that transcribes or organizes class material into lesson files, use
  `$japanese-class-notes`.
- For adding kanji and furigana to `Vocabulario` entries, use
  `$japanese-vocabulary-ruby`.
