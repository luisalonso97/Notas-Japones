\section{Decir si conooces o has visto a alguien Forma た}

ことがあります/ありません(か)。

Para hablar de cosas que haz hecho.

\begin{enumerate}
  \item ギターをひく。いいえ、ひだとはありません。
  \item 海でおよぐ。はい、およいだがあります。
  \item 外国に留学する。いいえ、留学したことはありません。
  \item Cien años de soledadを読む。いいえ、読んだことはありません。
  \item ゆめいな人に会う。はい、会ったことがあります。
  \item Cerro de la Sillaにのぼる。いいえ、のぼったはありません。
  \item むらかみの本を読む。いいえ、読んだことはありません。
  \item マジンガーZを見る。いいえ、見たことがあります。
  \item じゅぎょうをサボる。サボッタことがあります。
  \item テストで０てんをとる。いええ、とったことがあります。
\end{enumerate}

\section{Intensidad Extrema すぎます}

\begin{itemize}
  \item 漢字はむずかしすぎます。あまり好きじゃないです。
  \item 今日はひますぎます。ねむいです。
  \item 昨日の夜、飲みすぎました。
\end{itemize}

\begin{enumerate}
  \item この人はつかれすぎます。犬ははやいです。
  \item つかれました。テレビを見すぎました。
  \item 日本語のテストはかんたんすぎます。
  \item このえいがはつまらなすぎます。
  \item このふくは大きすぎます。
  \item 昨日、食べすぎました。
\end{enumerate}

\section{Contraste con が}
今冬ですが、あまりさむくないです。Ahora es invierno, pero no hace mucho frio.

魚も肉も好きですが、野菜わきらいです。Me gusta el pescado y la carne, pero no me gustan las verduras.

高すぎましたがかいました。

映画かんに行きたいんでが、
