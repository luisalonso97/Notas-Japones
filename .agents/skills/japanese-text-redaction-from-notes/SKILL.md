# Japanese text redaction from notes

Use this skill to create text given a user prompt.

## Skill/language level

The user is currently at a N5 level.
The level is a little over basic skill in all areas (writing, reading, speaking and listening).

## Text generation

- Do not use vocabulary or grammar that is above N5 level.
- Do not invent vocabulary, readings, grammar explanations that were not supplied or explicitly requested.

## Available vocabulary and grammar

- Treat the user's notes as a source to get context of kanji, vocabulary and grammar that the user knows and work primarily with those tools and nothing above that level.
- Do not use kanji that are outside of the kanji files. Ignore kanjis that are in the vocabulary sections of the notes that are not in the main Kanji notes, as those are primarily extra study content.
- Use the available grammar in the notes primarily instead of using more advanced grammar that could be more correct or natural.
- Treat the user's raw notes, photos, recordings, and corrections as the source of truth.

## Repository conventions

- Lessons live in `lvN/` as `lvN_leccion_NN.tex`.
- Kanji files live in `lvN/kanji/kanji.tex`.


## Output

For generated text output them into the session itself and prompt the user asking if the generated text should be saved to a file.

Files generated by this skill will be put inside the `generated/` directory with the following naming convention:
`generated_{timestamp}`
The timestamp should be generated with the following bash command: `date +%Y%m%d-%s`.
